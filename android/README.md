# UltraChat

Локальный P2P-мессенджер для Android, которому не нужен интернет и серверы.
Единственный канал связи — классический Bluetooth RFCOMM. Устройства находят
друг друга напрямую и обмениваются сообщениями, пока находятся рядом.

<p align="center">
  <b>Kotlin · Jetpack Compose · Material 3 · minSdk 24 · targetSdk 37</b>
</p>

## Что умеет

- **Локальный профиль** — никнейм и аватар хранятся в `SharedPreferences`. Аккаунтов и облака нет.
- **Только Bluetooth** — поиск устройств, RFCOMM-сервер и исходящее подключение. Wi-Fi Direct, интернет и TCP-порты не используются.
- **Простые аватары** — 12 офлайн-пресетов: инициалы и цветные эмодзи. Аватар выбирается в профиле и передаётся собеседнику вместе с `HELLO`.
- **Чат в духе Telegram** — спокойная тёмная палитра, список контактов, пузыри сообщений, время внутри пузыря, компактная шапка.
- **История** — переписка хранится локально по каждому устройству и восстанавливается после переподключения.
- **Очередь сообщений** — если сокет недоступен, сообщения ждут отправки и уходят после восстановления Bluetooth-канала.
- **Автоматическое переподключение** — при потере сокета приложение несколько раз пробует вернуть связь с тем же устройством.
- **Скрытая пасхалка** — 10 быстрых нажатий на аватар в профиле открывают ввод кода Создателя (`2252`). После активации:
  - в никнейме появляется префикс `[Создатель]`;
  - статус передаётся по воздуху и виден собеседнику;
  - аватар получает золотую корону.

## Стек

| Слой | Реализация |
|---|---|
| UI | Jetpack Compose, Material 3, собственная тёмная тема |
| Состояние | `AndroidViewModel`, `StateFlow` / `SharedFlow` |
| Связь | Bluetooth Classic RFCOMM: `listenUsingRfcommWithServiceRecord` / `createRfcommSocketToServiceRecord` |
| Протокол | построчный JSON: `HELLO`, `CHAT`, `PING`, `PONG` |
| Хранение | `SharedPreferences` для профиля и истории сообщений |

## Сборка

Требуются JDK 17+ (подойдёт JBR из Android Studio) и Android SDK с platform 37.

```powershell
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug
```

Готовый APK:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Установка на подключённое устройство:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

## Как пользоваться

1. Установите APK на два Android-устройства.
2. На обоих устройствах введите никнейм и выберите аватар.
3. Разрешите доступ к устройствам рядом и включите Bluetooth. На Android 11 и ниже также нужна геолокация.
4. Нажмите **«Искать по Bluetooth»** на обоих телефонах.
5. Выберите найденное устройство в списке «Рядом».
6. После handshake откроется чат. Если связь пропадёт, сообщения останутся в очереди, а приложение попробует переподключиться.

## Ограничения реальных устройств

- Приложение работает **без интернета**, но обоим устройствам нужен Bluetooth Classic (RFCOMM).
- На части прошивок для стабильного соединения требуется предварительное сопряжение устройств в системных настройках.
- На Android 12+ нужны `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `BLUETOOTH_ADVERTISE`; на Android 11 и ниже — разрешения геолокации для поиска.
- Если пользователь запретил разрешение навсегда, его нужно выдать в системных настройках приложения.
- История хранится только локально. При удалении приложения она удаляется.
- В отладочной сборке подпись debug; для распространения нужен release-ключ.

## Пасхалка

Аватар в профиле → 10 быстрых нажатий → код `2252`. Код намеренно не выводится
в интерфейсе. После активации префикс `[Создатель]` становится частью отображаемого
имени и передаётся в каждом `HELLO` и `CHAT`-кадре.
